# Labo's Linux

Deze repository hoort bij de cursussen *Linux* ("OpsLinux"), *Linux for Data Scientists* ("DataLinux") en *Linux & Data Processing Automation* ("DevLinux") in de professionele bacheloropleiding [toegepaste informatica](https://www.hogent.be/opleidingen/bachelors/toegepaste-informatica/) aan HOGENT. In deze repository vind je al het nodige om te kunnen werken aan de labo-opdrachten.

- Zie [deze pagina](info/git-instructies.md) voor instructies over het gebruik van Git en Github in deze cursus.

- Afhankelijk van je specifieke vak, vind je het **overzicht van de labo-opdrachten** die voor jou relevant zijn in volgende documenten:

    - [OpsLinux](info/opslinux.md)
    - [DataLinux, DevLinux](info/datalinux.md)

- In de directory `topics/` vind je de verschillende labo-opdrachten, gesorteerd per onderwerp. De README.md in elke directory bevat de opgaven en de nodige instructies om aan de slag te gaan. Je kan zelf bestanden toevoegen, bv. om je oplossingen of labo-nota's bij te houden.

## ⚠️⚠️⚠️ LET OP! ⚠️⚠️⚠️

- Deze repository is bedoeld voor je persoonlijke werk. Je bent dus vrij om deze te gebruiken zoals je dat zelf wil. Je mag er bestanden aan toevoegen, verwijderen, ...
- Je moet je oplossingen **niet "indienen"**, deze worden ook **niet nagekeken** door de lectoren.
- Er worden **geen modeloplossingen** gepubliceerd. Twijfel je over je oplossing of weet je niet hoe je aan een oefening moet beginnen? Vraag hulp tijdens de contactmomenten of op het forum op Orion!
- Repositories van studenten onder de [hogenttin](https://github.com/hogenttin) organisatie zullen worden opgeruimd voor het begin van het volgende academiejaar. **Zorg dus tijdig voor een backup!**
